## 4. 给 02 的集成参数

1. **单位图标**：透明底，直接叠在办公位/纸卡上，不加白卡底；F04 按 28–34px 渲染，F01 作角标 16–18px 时可加 1px `drop-shadow`（纸底尤其“责/船”奶油/青瓷块需要提边）。不要给 SVG 加描边或改色。
2. **棋子卡**：48×64 用 `background-size:100% 100%`；DOM 大字“贼/兵”22px（clustered 18px）居中；小图标 12–16px 贴左上 (2,2)，限制在 16×16 内；**左下角标 (2–18, 46–62) 不得被血条/图标覆盖**；右上折角 (33–46, 2–15) 保持可见。
3. **血条**：单条连续 3px + `当前/最大` 8–9px 数值，建议渲在棋子卡**下方**（沿用 0.7 敌人做法），数值叠在条上；若 02 要内嵌卡底，请从 x=18 起画，避开左下角标。
4. **clustered**：整卡缩到 30px 宽时，边框 2 单位≈1.25px，观感会比 2px 细；`displayY` 前后错位与 `horizontal_px_offset=0` 仍按配置，不得改回横向夹取。
5. **状态叠加**：`rooted`（责锁）、减速、眩晕、受击闪白等由 DOM 叠加，不要烘焙进棋子 SVG；两枚棋子只差角标色，其他样式保持一致。
6. **三通道**：颜色不是唯一通道——大字与小图标必须同时存在；不要把棋子的角标色当作唯一区分。
