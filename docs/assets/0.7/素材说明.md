## 6. 给 02 的集成参数（不改工程，只给参数）

1. **砖层**：三个 `tile-*.svg` 作为每格 `background-image`，`background-size:100% 100%; background-repeat:no-repeat`；80 格均为 DOM 元素，勿用整图替换棋盘。
2. **board-bg 叠层**：推荐 `position:absolute; inset:0; pointer-events:none`，放在砖层之上、单位/敌人/标记/查勘员之下（z-index 介于 2 与 3 之间）；木框仅压最外 16/800 与 16/1000（约 2%），不遮挡格中心 40px 交互区与路径箭头。若放在砖层之下，木框/四角印章会被砖遮挡，属预期，此时请用 CSS 提供外框；**不要**把 `board-bg` 做成 `background-size:cover` 的整板底图后再让格子错位。
3. **路线箭头**：`path-arrow.svg` 默认朝右；按第 5 节表旋转。建议渲染 10–14px；入口格 `[7,0]` 用 `marker-entry` 替代箭头，末格 `[7,9]` 不画箭头。
